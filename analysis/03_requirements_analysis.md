# Preliminary Requirement Recommendation

| Requirement | Source | Observation | description | Status |
|------------|------------|------------|------------|----------|
| REQ-001 | Architecture Analysis | Support Integrated and Independent modes | The controller shall support both Integrated Avionics Mode and Independent Navigator Mode.| Open |
| REQ-002 | Operational Evaluation | FMS2 parity with FMS1 | When operating in Independent Navigator Mode, all FMS2 functions shall provide operational parity with equivalent FMS1 functions.| Open |
| REQ-003 | Human Factors Review | Independent mode indication | The controller shall provide independent state indication for Navigator 1 and Navigator 2 operational modes.| Open |
| REQ-004 | User Testing | Cursor mode annunciation |The controller shall provide visual annunciation when Navigator 2 enters cursor or map manipulation modes. | Open |
